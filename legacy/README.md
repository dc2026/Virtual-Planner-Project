# Legacy Java Implementation

This folder contains the original Java/JavaFX implementation of the Virtual Planner project.

## Contents

- `src/` - Java source code for JavaFX desktop application
- `object_creation/` - Java class definitions for Task, Goal, Event entities
- `resources/` - FXML files for JavaFX UI
- `streamlit/` - Python Streamlit web application version
- `pom.xml` - Maven build configuration

## Note

This legacy code is preserved for reference only. The current active implementation is the React application in the `react-frontend/` directory.
